# SobStage v1.13.0 — release candidate

SobStage records up to eight external microphones at once, each to its own
file plus a summed mix, and sends one low-latency monitor mix to everyone in
the room. This release makes trouble impossible to miss: every
camera plugged in now records, anything that goes wrong mid-take sets off an
alarm, and starts and stops are announced. And each microphone now cries along
with you.

> **This is a release candidate, not a general release.** Physical-hardware
> validation is still open. See **Known limitations** below and
> [`RELEASE_CHECKLIST.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.0/RELEASE_CHECKLIST.md) before you trust it with
> a recording you can't repeat.

| `SHA256SUMS` | Checksums for every file above. |

This release is not code-signed with a Developer ID or Authenticode
certificate, the same as every release before it. On macOS, after dragging the
app to Applications, run this once in Terminal before the first launch,
otherwise Gatekeeper says the app "is damaged":

```sh
xattr -dr com.apple.quarantine "/Applications/SobStage.app"
```

On Windows, SmartScreen shows "unknown publisher" on first run. Choose
**More info → Run anyway**. Verify the download against `SHA256SUMS` first.

To check a download, see [Download in the README](https://github.com/taylordrew4u2/usbmic/blob/v1.13.0/README.md#download).

## What's new

- **Every camera plugged in records**, each to its own file, for the whole
  take. Switch one off in the Cameras panel if you don't want it; that choice
  is remembered.
- **Problems mid-take are an alarm, not a polite card.** A microphone
  unplugged or gone silent, a camera lost, sound dropped, the drive falling
  behind, the headphones gone: the whole window flashes red, a banner says
  SOMETHING IS WRONG in letters you can read across a room, and a siren plays
  in the headphones until you press Keep recording or Stop recording.
- **Starts and stops are announced.** For three seconds the window flashes
  RECORDING (red) or RECORDING STOPPED (cyan) with the take's name, and the
  headphones play a rising chirp for a start and a falling one for a stop.
- If your system is set to reduce motion, the alarm and banners pulse once a
  second instead of flashing.
- **Each microphone strip wears the app's crying face.** It frowns while
  quiet, sheds a cyan tear when the mic gets loud, sobs with two when it
  clips, and closes its eyes when there's no signal. The level ring, track and
  number work exactly as before.

## Fixes

- When the headphone output and a microphone both had a problem, only the
  headphones were mentioned. Both are said now.
- On Linux test builds, ALSA's `default`, `sysdefault` and `dsnoop` aliases no
  longer show up as an extra, silent microphone.

Everything in [v1.12.1](https://github.com/taylordrew4u2/usbmic/releases/tag/v1.12.1) is included.
Full details: [`CHANGELOG.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.0/CHANGELOG.md).

## Known limitations

- **No completed take from physical microphones has passed the release
  hardware matrix yet**, on any platform. The engine is covered by 595 unit
  tests and by simulated CoreAudio and WASAPI device layers, but simulation is
  not hardware certification.
- **Pulling the card mid-take** is handled in code, and an automated test
  makes the recording folder stop answering inside the real app at Record and
  at Stop. It has not yet been tested by pulling a real card on macOS or
  Windows.
- **HDMI capture cards:** a visible preview and a completed camera recording
  have not yet been verified on this release, including with every camera now recording by default.
- **Phones and wireless receivers that present as ordinary USB audio** can't be
  told apart from an interface, so they may appear as inputs.
- **Monitor latency** has not been measured by loopback on real hardware.
- **Linux** is for early use and testing only.

## Updating and rolling back

There is no automatic update. Download the new version and replace the old
one. Your settings, microphone names and recordings are kept.

If this version causes you a problem, v1.12.1 and v1.12.0 remain available. Back up
`settings.json` before you downgrade. Rolling back never deletes recordings.

## Support and privacy

- Report a problem: [open an issue](https://github.com/taylordrew4u2/usbmic/issues/new).
  **Settings → Export diagnostics** creates a zip of logs, recent session
  details and device names. It never contains audio or video. Read it before
  posting it publicly.
- SobStage sends nothing anywhere. There is no crash upload, analytics or
  automatic update. See [`PRIVACY.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.0/PRIVACY.md).
