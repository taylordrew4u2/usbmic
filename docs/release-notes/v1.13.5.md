# SobStage v1.13.5 — release candidate

SobStage records up to eight external microphones at once, each to its own
file plus a summed mix, and sends one low-latency monitor mix to everyone in
the room. This is a Mac fix release on v1.13.4: four fixes that
matter during a show.

> **This is a release candidate, not a general release.** Physical-hardware
> validation is still open. See **Known limitations** below and
> [`RELEASE_CHECKLIST.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.5/RELEASE_CHECKLIST.md) before you trust it with
> a recording you can't repeat.

## Downloads

| File | For |
|---|---|
| `SobStage-macOS.dmg` | macOS 13 or later, Apple silicon and Intel. Open it and drag SobStage onto Applications. |
| `SobStage-macOS.zip` | The same app, without the disk image. |
| `SobStage-Windows.zip` | Windows. Portable: unzip and run `SobStage.exe`. No installer. |
| `SobStage-Linux.zip` | Linux (early use; not a v1 production target). |
| `SobStage-1.13.5-source.zip` | The exact SobStage and JUCE source this release was built from (GPLv3). |
| `SHA256SUMS` | Checksums for every file above. |

This release is not code-signed with a Developer ID or Authenticode
certificate, the same as every release before it. On macOS, after dragging the
app to Applications, run this once in Terminal before the first launch,
otherwise Gatekeeper says the app "is damaged":

```sh
xattr -dr com.apple.quarantine "/Applications/SobStage.app"
```

On Windows, SmartScreen shows "unknown publisher" on first run. Choose
**More info → Run anyway**. Verify the download against `SHA256SUMS` first.

To check a download, see [Download in the README](https://github.com/taylordrew4u2/usbmic/blob/v1.13.5/README.md#download).

## What's new

- **Pressing Return can no longer stop a take by accident.** After you
  clicked Start recording, the record button kept the keyboard, so a stray
  Return stopped the take -- including behind the mid-take alert card, where
  Return means "keep recording". Return now only answers the card on screen.
- **Camera gesture Reactions no longer end up in your recordings.** macOS
  draws fireworks, balloons and confetti into the camera picture when someone
  gives a thumbs-up or peace sign; SobStage now turns those effects off by
  default. If you switched them on for SobStage in the menu-bar Video menu,
  turn them off there.
- **Record waits until you answer the microphone permission message.**
  While macOS is still asking whether SobStage may use your microphones,
  Record stays off and tells you to click Allow; it turns on a moment after
  you do. Before, a take started then recorded silence.
- **The recorder protects the separate tracks and the backup even when
  other warnings keep appearing.** When the drive falls behind, the app
  switches to the mixed file in time, and it stops the backup copy before it
  fills your disk. A steady stream of glitch or overload warnings used to
  hold both back.

**Before a show:** set your microphones and headphones to the same sample rate
as SobStage in **Audio MIDI Setup** (48 kHz is safest), allow the microphone
prompt, and make a short test take.

Everything in [v1.13.4](https://github.com/taylordrew4u2/usbmic/releases/tag/v1.13.4) is included, including its macOS 27 launch-crash fix.
Full list: [`CHANGELOG.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.5/CHANGELOG.md).

## Known limitations

- **No completed take from physical microphones has passed the release
  hardware matrix yet**, on any platform. The engine is covered by 662 unit
  tests and by simulated CoreAudio and WASAPI device layers, but simulation is
  not hardware certification.
- **Pulling the card mid-take** is handled in code, and an automated test
  makes the recording folder stop answering inside the real app at Record and
  at Stop. It has not yet been tested by pulling a real card on macOS or
  Windows.
- **HDMI capture cards:** a visible preview and a completed camera recording
  have not yet been verified on this release, including with every camera now recording by default.
- **Phones and wireless receivers that present as ordinary USB audio** can't be
  told apart from an interface, so they may appear as inputs.
- **Monitor latency** has not been measured by loopback on real hardware.
- **Linux** is for early use and testing only.

## Updating and rolling back

There is no automatic update. Download the new version and replace the old
one. Your settings, microphone names and recordings are kept. 

If this version causes you a problem, v1.13.4 remains available. Back up
`settings.json` before you downgrade. Rolling back never deletes recordings.

## Support and privacy

- Report a problem: [open an issue](https://github.com/taylordrew4u2/usbmic/issues/new).
  **Settings → Export diagnostics** creates a zip of logs, recent session
  details and device names. It never contains audio or video. Read it before
  posting it publicly.
- SobStage sends nothing anywhere. There is no crash upload, analytics or
  automatic update. See [`PRIVACY.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.5/PRIVACY.md).
