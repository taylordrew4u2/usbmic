# SobStage v1.13.2 — release candidate

SobStage records up to eight external microphones at once, each to its own
file plus a summed mix, and sends one low-latency monitor mix to everyone in
the room. This is a bug-fix release on v1.13.1: 46 fixes, each
proven by a test that failed before the fix and passes after it.

> **This is a release candidate, not a general release.** Physical-hardware
> validation is still open. See **Known limitations** below and
> [`RELEASE_CHECKLIST.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.2/RELEASE_CHECKLIST.md) before you trust it with
> a recording you can't repeat.

This release is not code-signed with a Developer ID or Authenticode
certificate, the same as every release before it. On macOS, after dragging the
app to Applications, run this once in Terminal before the first launch,
otherwise Gatekeeper says the app "is damaged":

```sh
xattr -dr com.apple.quarantine "/Applications/SobStage.app"
```

On Windows, SmartScreen shows "unknown publisher" on first run. Choose
**More info → Run anyway**. Verify the download against `SHA256SUMS` first.

To check a download, see [Download in the README](https://github.com/taylordrew4u2/usbmic/blob/v1.13.2/README.md#download).

## What's new

46 bugs fixed; nothing added. The ones you are most likely to notice:

**Recordings you keep**
- A long take's combined video keeps its sound to the end, past the point
  where the mix file splits.
- Unplugging the headphones mid-take no longer shortens the recording or
  pulls the sound out of line with the camera.
- A microphone that stops sending audio is reopened for the next take instead
  of quietly recording silence; if it stays dead, the take says so.
- Recovered takes are repaired into valid WAV files, and the recovered card
  no longer calls files it couldn't fix "playable".
- A second Quit while the camera files finish no longer cuts the movie short.
- Plugging in or pulling out a second camera of the same model no longer
  stops the one recording.

**Platform fixes**
- Windows: recording into a folder with an accent in its path works; audio a
  driver drops is counted; mono and four-channel headphone outputs are no
  longer refused.
- macOS: unplugging one interface no longer locks out every microphone until
  a restart.
- Linux: a multi-input interface records every input, and keeps its strips
  when something else is plugged in.

**Warnings that tell the truth**
- A stalled drive raises the alarm once; a stalled writer is caught even
  while a camera records; after the tracks drop to mix-only the warning no
  longer says nothing was lost.
- Record comes back once a card that couldn't be written is fixed, and the
  reason says "couldn't write", not "too slow".
- Each take's `session.json` lists only its own buffer changes and dropouts,
  with the dropped-frame count and the right times.

**Everyday use**
- The space bar mutes the headphones even after clicking a microphone's strip,
  and muting no longer comes undone on its own.
- Clearing a microphone's or camera's name gives it back its own name.
- Trim is kept per input on an interface, and Settings' sliders follow renamed
  and swapped microphones.
- Installing ffmpeg while SobStage is open takes effect on the next take.
- Short loud peaks show on the meters; the bottom row and the time-left text
  stay readable in small or narrow windows.

Everything in [v1.13.1](https://github.com/taylordrew4u2/usbmic/releases/tag/v1.13.1) is included.
Full list: [`CHANGELOG.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.2/CHANGELOG.md).

## Known limitations

- **No completed take from physical microphones has passed the release
  hardware matrix yet**, on any platform. The engine is covered by 643 unit
  tests and by simulated CoreAudio and WASAPI device layers, but simulation is
  not hardware certification.
- **Pulling the card mid-take** is handled in code, and an automated test
  makes the recording folder stop answering inside the real app at Record and
  at Stop. It has not yet been tested by pulling a real card on macOS or
  Windows.
- **HDMI capture cards:** a visible preview and a completed camera recording
  have not yet been verified on this release, including with every camera now recording by default.
- **Phones and wireless receivers that present as ordinary USB audio** can't be
  told apart from an interface, so they may appear as inputs.
- **Monitor latency** has not been measured by loopback on real hardware.
- **Linux** is for early use and testing only.

## Updating and rolling back

There is no automatic update. Download the new version and replace the old
one. Your settings, microphone names and recordings are kept. Trims set on a single input of an interface are new in
this version; an older version reads the file and ignores them.

If this version causes you a problem, v1.13.1 and v1.13.0 remain available. Back up
`settings.json` before you downgrade. Rolling back never deletes recordings.

## Support and privacy

- Report a problem: [open an issue](https://github.com/taylordrew4u2/usbmic/issues/new).
  **Settings → Export diagnostics** creates a zip of logs, recent session
  details and device names. It never contains audio or video. Read it before
  posting it publicly.
- SobStage sends nothing anywhere. There is no crash upload, analytics or
  automatic update. See [`PRIVACY.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.2/PRIVACY.md).
