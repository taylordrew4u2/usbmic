# SobStage v1.13.9 — release candidate

SobStage records up to eight external microphones at once, each to its own
file plus a summed mix, and sends one low-latency monitor mix to everyone in
the room. This release is eleven more Mac fixes: the window, stray key
and trackpad changes, identical mics, cards that stall or are formatted
FAT32, and an honest monitor latency.

> **This is a release candidate, not a general release.** Physical-hardware
> validation is still open. See **Known limitations** below and
> [`RELEASE_CHECKLIST.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.9/RELEASE_CHECKLIST.md) before you trust it with
> a recording you can't repeat.

| `SobStage-1.13.9-source.zip` | The exact SobStage and JUCE source this release was built from (GPLv3). |
| `SHA256SUMS` | Checksums for every file above. |

This release is not code-signed with a Developer ID or Authenticode
certificate, the same as every release before it. On macOS, after dragging the
app to Applications, run this once in Terminal before the first launch,
otherwise Gatekeeper says the app "is damaged":

```sh
xattr -dr com.apple.quarantine "/Applications/SobStage.app"
```

On Windows, SmartScreen shows "unknown publisher" on first run. Choose
**More info → Run anyway**. Verify the download against `SHA256SUMS` first.

To check a download, see [Download in the README](https://github.com/taylordrew4u2/usbmic/blob/v1.13.9/README.md#download).

## What's new

- **The window stays on its display.** Opening Settings, Help or a
  camera no longer moves a window on an external monitor back onto the
  laptop, and no longer slides the title bar under the menu bar.
- **Arrow keys and trackpad scrolling no longer change settings.**
  Up/Down after clicking a Settings picker used to switch the headphone
  output, drive, rate or bit depth; a two-finger scroll over the volume or a
  trim slider changed the level.
- **Two identical microphones switch correctly.** The on/off, input and
  headphone switches act on the one you clicked, not the first of the pair.
- **A card that stops answering can't freeze the window.** Choosing a
  new save location, or the check right after Stop, no longer hangs on a
  wedged card, and the folder chooser no longer opens on it.
- **A slow card still writing at Stop is waited for.** It used to be
  reported as having stopped answering: the final session.json was skipped,
  the take came back as "interrupted", and the combined video was cut short.
- **FAT32 (MS-DOS) cards are refused when a camera is on**, with how to
  fix it. The movie is one file and stopped at 4 GB, about 18 minutes in.
  Audio-only recording to FAT32 still works.
- **"SobStage isn't allowed to save here"** when macOS privacy settings
  block the folder, instead of telling you to re-seat a card that is fine.
  A locked or full card is named as such.
- **The drive check no longer leaves 200 MB files behind** after a quit
  or crash during it, and clears any left by earlier versions.
- **Monitor latency shows the real figure**, including what the output
  device adds. Bluetooth headphones showed about 3 ms; they now show their
  real 150 ms or more.
- **A mixer that is also the headphone output keeps recording** when a
  second, separate mic fails to open, instead of closing the whole rig.
- **The combine ("Also save video with the sound") yields the card** to the
  next take recording on it, and an ffmpeg that can't run on this Mac (an
  Intel build without Rosetta) is skipped instead of failing every take.

**Before a show:** set your microphones and headphones to the same sample rate
as SobStage in **Audio MIDI Setup** (48 kHz is safest), allow the microphone
prompt, and make a short test take.

Everything in [v1.13.8](https://github.com/taylordrew4u2/usbmic/releases/tag/v1.13.8) is included.
Full list: [`CHANGELOG.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.9/CHANGELOG.md).

## Known limitations

- **No completed take from physical microphones has passed the release
  hardware matrix yet**, on any platform. The engine is covered by 701 unit
  tests and by simulated CoreAudio and WASAPI device layers, but simulation is
  not hardware certification.
- **Pulling the card mid-take** is handled in code, and an automated test
  makes the recording folder stop answering inside the real app at Record and
  at Stop. It has not yet been tested by pulling a real card on macOS or
  Windows.
- **HDMI capture cards:** a visible preview and a completed camera recording
  have not yet been verified on this release, including with every camera now recording by default.
- **Phones and wireless receivers that present as ordinary USB audio** can't be
  told apart from an interface, so they may appear as inputs.
- **Monitor latency** has not been measured by loopback on real hardware.
- **Linux** is for early use and testing only.

## Updating and rolling back

There is no automatic update. Download the new version and replace the old
one. Your settings, microphone names and recordings are kept. 

If this version causes you a problem, v1.13.8 remains available. Back up
`settings.json` before you downgrade. Rolling back never deletes recordings.

## Support and privacy

- Report a problem: [open an issue](https://github.com/taylordrew4u2/usbmic/issues/new).
  **Settings → Export diagnostics** creates a zip of logs, recent session
  details and device names. It never contains audio or video. Read it before
  posting it publicly.
- SobStage sends nothing anywhere. There is no crash upload, analytics or
  automatic update. See [`PRIVACY.md`](https://github.com/taylordrew4u2/usbmic/blob/v1.13.9/PRIVACY.md).
